# Roadmap

## Phase 0 — Verified foundation

- Public Next.js product shell
- Deterministic case demo
- Health and OpenAPI endpoints
- CI, type checking and build verification
- Honest capability reporting

## Phase 1 — Evidence Core

- Authenticated case creation
- Private evidence storage
- PDF/text/chat/code ingestion
- Evidence hashes and provenance
- Timeline reconstruction
- Contradiction detection
- On-chain read-only investigation
- Source-linked findings

## Phase 2 — Decision Support

- Retrieval/RAG over approved evidence
- Similar-case search
- Exportable evidence report
- Multilingual analysis
- Rate limits and audit logs
- Pilot workflows
- Kleros-compatible evidence submission

## Phase 3 — Custody + Settlement

- Smart custody contracts
- Explicit user authorization
- Testnet deployment first
- Transaction simulation and monitoring
- Settlement only after authorized arbitration result
- Independent contract security review

## Phase 4 — Autonomous Economy

- Agent-facing API
- Agent identity/authentication
- Multi-chain adapters
- DAO integrations
- Production observability
- Commercial API/SaaS
