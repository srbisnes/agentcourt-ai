# Investor Brief

## Thesis

AgentCourt AI is building an **evidence intelligence layer for the autonomous economy**.

As software agents transact, hire services and execute agreements, disputes become machine-generated but still require human-verifiable evidence. AgentCourt AI is designed to reduce the cost and time of reviewing that evidence.

## Wedge

Start with evidence-heavy decentralized dispute workflows. Do not replace arbitrators; make their review faster, clearer and more auditable.

## Moat direction

- Evidence provenance and normalized evidence graphs
- Source-linked findings
- Domain-specific dispute datasets with appropriate permissions
- Protocol integrations
- Agent-facing APIs
- Auditability and human-controlled decisions

## Monetization direction

- SaaS for DAOs, marketplaces and protocol teams
- API licensing for agent platforms
- Enterprise evidence-intelligence workflows
- Optional transaction/custody fees only after secure implementation

## Current truth

The repository is a verified foundation, not a production arbitration platform. Live AI, persistence, custody and arbitration integrations are roadmap items.
