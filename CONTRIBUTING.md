# Contributing to AgentCourt AI

Thank you for your interest in contributing.

AgentCourt AI is currently in early public demo stage. The highest-value contributions are those that respect the core principles:

- Evidence ≠ Inference
- Decision support, not automated justice
- Explicit honesty about what is and is not live
- Full source attribution and confidence scores

## Ways to Contribute

1. **Product & UX feedback** on the live demo (https://agentcourt-ai.vercel.app)
2. **Documentation** improvements
3. **Architecture and design** discussions (open an issue first)
4. **Security** reports (see SECURITY.md — private disclosure preferred)
5. **Code** for the evidence pipeline once the public roadmap items open

## Process

1. Open an issue describing the problem or idea before large PRs.
2. Keep changes focused and well-documented.
3. Do not introduce production claims or features that are not yet implemented.
4. Respect the capability-flag pattern in the health endpoint.

## Code of Conduct

Be respectful, precise and constructive. This project exists to improve trust infrastructure; contributors are expected to model the same clarity and integrity the product aims for.

## Questions

Reach out via the X account listed in the README or open a GitHub issue for non-security topics.
